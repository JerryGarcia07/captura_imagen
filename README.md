# CaptureImg — Manual de usuario

Bienvenido a **CaptureImg**, una web para crear imágenes personalizadas sin necesidad de programas de diseño. Puedes generar **iconos**, **tarjetas de anime** y **carpetas de K-pop** desde tu navegador, ver el resultado en vivo y descargarlo o compartirlo.

Todo el trabajo se hace **en tu propio navegador**: tus imágenes no se suben a ningún servidor.

---

## 1. Antes de empezar

### 1.1 Qué necesitas

- Un navegador moderno (Chrome, Edge, Firefox o Safari actualizados).
- Conexión a internet, solo si vas a **buscar** imágenes o datos en línea.
- Una imagen propia en tu equipo, si prefieres subirla tú en lugar de buscarla.

### 1.2 Cómo entrar

Abre la web y llegarás a la **pantalla de inicio**, titulada _“Generar Imagen”_. Allí verás tres tarjetas:

| Tarjeta           | Para qué sirve                                        |
| ----------------- | ----------------------------------------------------- |
| **Crear Icon**    | Diseñar un icono con caja, lomo lateral y portada     |
| **Tarjeta Anime** | Crear una ficha de anime con póster, datos y sinopsis |
| **Carpeta K-pop** | Crear una carpeta decorada con pestaña y portada      |

Haz clic en cualquiera de ellas para empezar. Para volver al inicio en cualquier momento, pulsa el logo **CaptureImg** de la esquina superior izquierda.

---

## 2. Elementos comunes a todas las pantallas

Todas las herramientas comparten la misma distribución:

- **Cabecera**: a la izquierda el logo (vuelve al inicio) y a la derecha el botón de **tema claro/oscuro** (icono de sol o luna). Tu preferencia se recuerda la próxima vez que entres.
- **Panel izquierdo (naranja)**: el formulario. Aquí escribes, buscas y eliges opciones.
- **Panel derecho**: la **vista previa**. Se actualiza automáticamente cada vez que cambias algo.
- **Botones de acción** al final del formulario:
  - **Descargar**: guarda la imagen en tu equipo.
  - **Limpiar**: borra todos los campos y reinicia el diseño.
  - **Compartir en Redes**: abre el menú de compartir de tu dispositivo (móvil, tablet o navegador compatible).
- **Mensajes en rojo**: indican qué falta o que la búsqueda no encontró resultados.

> 💡 **Consejo**: el botón de búsqueda también funciona pulsando la tecla **Enter** dentro del campo de búsqueda.

## 3. Crear un icono

Ruta: tarjeta **“Crear Icon”**.

### Paso a paso

1. **Busca una imagen o sube la tuya**
   - **Opción A — Buscar**: escribe el nombre de una película, serie o persona en el campo _“Buscar en TMDB…”_ y pulsa el botón de la lupa (o Enter). Se cargará automáticamente el nombre y el póster del primer resultado que tenga imagen.
   - **Opción B — Subir**: pulsa _“Seleccionar archivo”_ y elige una imagen de tu equipo (JPG, PNG, etc.).
2. **Revisa el nombre**: aparece en el campo _“Nombre (Editable)”_. Puedes cambiarlo libremente; es el texto que se verá en el lomo del icono.
3. **Elige el color del lomo**: usa el selector _“Color de fondo”_.
4. **Elige el formato de descarga** (ver la tabla de la sección 6).
5. Pulsa **Descargar** para guardar la imagen o **Compartir en Redes** para enviarla.

### Qué pasa si no encuentra resultados

Si TMDB no encuentra nada, aparecerá una ventana con el mensaje _“No hay resultados”_. Pulsa **Entendido**, prueba con otro nombre o sube tu propia imagen.

### Reglas para descargar

Para poder descargar necesitas:

- Un **nombre** escrito.
- Una **imagen** seleccionada o subida.
- Un **formato** elegido (siempre hay uno preseleccionado).

Si falta algo, verás un aviso en rojo y no se generará el archivo.

## 4. Crear una tarjeta de anime

Ruta: tarjeta **“Tarjeta Anime”**.

Esta herramienta rellena automáticamente los datos del anime por ti.

### Paso a paso

1. **Busca el anime**: escribe su nombre en el buscador (por ejemplo, _“Kusuriya no Hitorigoto”_) y pulsa la lupa o Enter. Mientras busca verás un indicador giratorio.
2. **Revisa los datos autocompletados**. La web combina dos fuentes para darte la mejor información:
   - De la base de datos de anime obtiene **título, episodios, año, tipo, estudio, géneros y puntuación**.
   - De la base de datos de cine/series obtiene la **sinopsis en español** y el **póster**.
   - Los géneros se traducen automáticamente al español (por ejemplo, _Action_ → _Acción_).
3. **Ajusta lo que quieras**. Todos los campos son editables:
   - **Nombre**
   - **Episodios** (si el anime está en emisión puede aparecer _“En emisión”_)
   - **Año**
   - **Tipo**: TV, Película, OVA, ONA o Especial
   - **Studio**
   - **Géneros**
   - **Puntaje** (por ejemplo, 8.5)
   - **Sinopsis**
4. **Cambia el póster si lo deseas**: usa _“Seleccionar archivo”_ para subir tu propia imagen.
5. **Decide si quieres mostrar la puntuación en la tarjeta**: marca la casilla _“Mostrar Puntuación en la tarjeta”_. Si la marcas, el puntaje aparecerá en grande sobre el póster.
6. **Elige el formato** (PNG, JPG o WEBP; esta herramienta no genera ICO).
7. Pulsa **Descargar** o **Compartir en Redes**.

### Si el anime no aparece en la base de datos principal

La web intentará rellenar la ficha con información básica de la otra base de datos. Verás un aviso amarillo indicando que los datos son limitados. Puedes completar los campos a mano.

### Si no encuentra nada

Aparecerá la ventana _“No hay resultados”_. Prueba escribiendo el **título oficial** (a veces en inglés o en japonés romanizado) o sube tú mismo la imagen.

### Reglas para descargar

En esta herramienta solo son obligatorios el **nombre** y la **imagen**. El resto de campos son opcionales y, si están vacíos, la tarjeta mostrará textos de relleno (por ejemplo, _“Caps: --”_).

## 5. Crear una carpeta de K-pop

Ruta: tarjeta **“Carpeta K-pop”**.

### Paso a paso

1. **Busca el grupo o álbum**: escribe su nombre en el buscador y pulsa la lupa o Enter. La web consulta la tienda de iTunes y toma la portada del primer álbum encontrado.
2. **Revisa el nombre**: se rellena con el nombre del álbum (o del artista si no hay álbum). Puedes editarlo.
3. **Cambia la portada si quieres**: usa _“Seleccionar archivo”_ para subir tu propia imagen.
4. **Personaliza los colores**:
   - **Color de la pestaña**: el fondo de la lengüeta superior de la carpeta.
   - **Color del texto**: el color del nombre que aparece en la pestaña.
5. **Elige el formato de descarga** (ICO, PNG, JPG o WEBP).
6. Pulsa **Descargar** o **Compartir en Redes**.

### Reglas para descargar

Igual que en el icono: necesitas **nombre**, **imagen** y **formato**. Si falta alguno, verás un aviso en rojo.

### Si no encuentra el álbum

Aparecerá la ventana _“No hay resultados”_. Prueba con el nombre del grupo, del álbum o en inglés. También puedes subir la portada manualmente.

---

## 6. Formatos de descarga

| Formato  | Mejor para                  | Detalles                                                                          |
| -------- | --------------------------- | --------------------------------------------------------------------------------- |
| **PNG**  | Uso general, transparencias | La opción más versátil. Fondo transparente donde el diseño lo permita.            |
| **JPG**  | Fotos y uso cotidiano       | Fondo blanco fijo (no admite transparencia). Archivo más ligero.                  |
| **WEBP** | Webs y páginas modernas     | Buena calidad con archivos pequeños.                                              |
| **ICO**  | Iconos de Windows           | Se genera a 128 × 128 píxeles. Solo disponible en _Crear Icon_ y _Carpeta K-pop_. |

La imagen se guarda con el **nombre que escribiste** en el formulario. Si dejas el nombre vacío, se usará _“CaptureImg”_.

> 💡 **Consejo**: para usar un icono en Windows, descarga el formato **ICO**. Para redes sociales o mensajería, **PNG** suele ser la mejor opción.

---

## 7. Compartir la imagen

El botón **Compartir en Redes** abre el menú nativo de tu dispositivo para enviar la imagen a otras aplicaciones (WhatsApp, Telegram, correo, etc.).

- Funciona en **móviles y tablets** y en navegadores compatibles.
- La imagen se comparte siempre como **PNG**.
- Si tu navegador no lo admite, verás un aviso; en ese caso, usa **Descargar** y comparte el archivo manualmente.

---

## 8. Consejos rápidos

- **La vista previa es exactamente lo que descargas**: lo que ves en el panel derecho es lo que se guarda.
- **La imagen se adapta al marco**: si tu foto es vertical u horizontal, se recortará para encajar. Elige una imagen con la proporción adecuada para evitar cortes.
- **Usa imágenes de buena calidad**: al descargar se genera una versión al doble de resolución, así que una imagen nítida dará un mejor resultado.
- **Puedes escribir libremente**: todos los campos de texto admiten acentos, emojis y caracteres especiales.
- **Prueba varias veces sin miedo**: el botón **Limpiar** reinicia todo y no borra nada de tu equipo.
- **El tema oscuro es el predeterminado**: cámbialo con el botón de sol/luna si prefieres fondo claro.

## 9. Preguntas frecuentes

**¿Necesito crear una cuenta?**
No. La web funciona sin registro ni inicio de sesión.

**¿Se guardan mis imágenes en algún servidor?**
No. Las imágenes que subes permanecen en tu navegador y se usan solo para la vista previa y la descarga.

**¿Por qué no aparece el botón de descarga o no hace nada?**
Comprueba que hayas escrito un nombre y seleccionado una imagen. El botón también se bloquea unos segundos mientras se genera el archivo (verás _“Procesando…”_).

**La búsqueda no encuentra mi anime o grupo. ¿Qué hago?**
Prueba con el título oficial, en inglés o con otra variante del nombre. Si sigue sin aparecer, sube tu propia imagen y escribe los datos manualmente.

**¿Puedo usar las imágenes que genero libremente?**
Puedes descargarlas y usarlas, pero ten en cuenta que las imágenes y datos obtenidos de internet (pósters, portadas, sinopsis) pertenecen a sus respectivos autores. Úsalas de forma responsable.

**¿Por qué la tarjeta de anime no ofrece formato ICO?**
Porque está pensada como una ficha para compartir, no como un icono. Para iconos usa _Crear Icon_.

**¿Puedo volver atrás o recuperar un diseño anterior?**
No se guarda historial. Si cierras o recargas la página, el diseño se pierde. Descarga tu imagen antes de salir.

**Veo una página “404 – Página no encontrada”.**
La dirección que abriste no existe. Pulsa **“Volver al inicio”** para regresar a la pantalla principal.

---

## 10. Resumen de una creación típica

1. Elige una herramienta en el inicio.
2. Busca o sube una imagen.
3. Ajusta nombre, colores y datos.
4. Comprueba la vista previa.
5. Elige el formato.
6. Pulsa **Descargar** o **Compartir**.
7. ¡Listo! Tu imagen está en tu equipo.
